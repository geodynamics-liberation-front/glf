About

The Geodynamics Liberation Front is a one-desk outfit for tech, education and science projects. The name comes from geophysics, and so do many of the projects. The rest come from wherever curiosity leads.

What this is

A catalog of things we have made and think are worth sharing: interactive web pages, printable booklets and charts, and the tools behind them. Each one tries to do a single job well and to show its work. Where a project uses data, the sources are cited and the code that processed them is published with it.

Where to find us

  • GitHub. Every project is a public repository under the geodynamics-liberation-front organization. Issues and pull requests are welcome.
  • Facebook. Announcements and the occasional picture of a rock.

How this site is built

The site lives in its own repository. A list of published projects names each project's repository. When the site is built, every project is checked out at the tip of its main branch, built with its own build steps, and placed under /projects/. The catalog page records which commit each project was built from, so what you see here is always the most recent published version.

Credits

The stripes on the front page follow the geomagnetic polarity time scale for the last 5.3 million years, drawn symmetrically about a spreading ridge in the manner of Vine and Matthews. Type is set in Bricolage Grotesque and Source Serif 4.
