Geodynamics Liberation Front

The Geodynamics Liberation Front is an outreach organization that exposes students and the general public to scientific concepts, using the Earth and Earth processes as a tool to teach science, technology, engineering, arts and math.

Most of what we make is small and open: a web page that answers one question well, a printable thing for a classroom, a program you can read. Every project lives in a public repository, and this site is rebuilt from the latest version of each one.
