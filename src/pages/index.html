Small tools, games and printed things for seeing how the Earth works. Nominally about geophysics. In practice, about whatever we are curious enough to build.

The stripes above are real: the record of the Earth's magnetic field reversing over the last 5.3 million years, frozen into the sea floor as it spreads away from a ridge. Every project here is like that. Something you can look at, and something you can check.

What we make

Interactive pages that answer one question well: what is across the ocean from here, what two sound waves do when they meet, where a plate boundary runs.

Printable things for classrooms and kitchen tables. Passports, charts, cut-and-fold models, with the data and the code that made them.

Code for anyone to read. Every project is a public repository on GitHub, and this site rebuilds itself from the latest version of each one.
